# React 10차 — 대시보드 실데이터 연결 및 빠른 이동

## 목표

기존 대시보드의 임시 안내 문구를 제거하고, 현재 백엔드에서 제공하는 게시판·게시글 조회 API를 이용하는 실제 요약 화면으로 바꿉니다.

## 변경 파일

- `front/src/pages/DashboardPage.jsx` — 기존 파일 교체
- `front/dashboard-overview.css.txt` — 내용을 `front/src/App.css` 맨 아래에 추가

## 구현 내용

- 게시판 조회 API로 게시판 수 표시
- 각 게시판에서 최신 게시글 3개씩 조회한 뒤 생성일 기준으로 정렬하고 최대 6개 표시
- API가 반환한 `totalElements`를 합산해 게시판별 전체 게시글 수 표시
- 관리자에게만 게시판/게시글 관리 바로가기 표시
- 로딩, 전체 오류, 일부 게시판 조회 실패, 빈 게시판/게시글 상태 처리
- 새로고침 버튼으로 대시보드 데이터를 다시 조회
- 기존 계정 정보 표시 유지
- 모바일 폭에서 요약 카드, 최근 글, 바로가기 레이아웃을 한 열로 전환

## API 사용

기존 `boardApi.getBoards()`와 `boardApi.getPosts(boardId, { page: 0, size: 3 })`만 사용합니다. 백엔드 API 변경은 포함하지 않습니다.

최근 게시글은 별도 전체 피드 API가 없기 때문에 **각 게시판의 첫 페이지(최신순 3개)**를 모아 프론트엔드에서 정렬합니다. 한 게시판의 글이 3개를 초과하더라도 전체 게시글 수는 응답의 `totalElements`를 사용합니다. 일부 게시판 조회가 실패하면 나머지 게시판 결과를 계속 보여주고 실패 개수를 안내합니다.

## 적용 방법

1. ZIP 안의 `front/src/pages/DashboardPage.jsx`를 저장소의 동일 경로에 덮어씁니다.
2. `front/dashboard-overview.css.txt` 내용을 `front/src/App.css` 끝에 추가합니다. 기존 `App.css`를 교체하지 않습니다.
3. 프론트엔드를 실행한 뒤 `/dashboard`에서 요약 카드, 최근 게시글, 빠른 이동, 새로고침 및 모바일 레이아웃을 확인합니다.

## 검증 범위

이 패치 파일 기준 JSX 문법 파싱, CSS 중괄호 균형, ZIP 무결성 검사를 수행합니다. 실제 브라우저에서 백엔드와 연결한 통합 확인은 적용 환경에서 수행해야 합니다.
