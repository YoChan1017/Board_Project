# Board_Project 프론트엔드 3차 작업

## 이번 단계
- 게시글 제목을 클릭하면 상세 페이지(`/posts/:postId`)로 이동
- 게시글 상세 내용, 작성자, 작성일, 조회수, 좋아요 수 표시
- 게시판에서 글쓰기 버튼을 누르면 작성 페이지(`/boards/:boardId/posts/new`)로 이동
- 카테고리 선택(선택 사항), 제목(최대 200자), 내용 입력 및 게시글 등록
- 등록 성공 시 새 게시글 상세 페이지로 이동
- 인증 토큰은 기존 Axios 클라이언트가 자동으로 전달

## 확인 순서
1. 로그인합니다.
2. 상단 메뉴에서 게시판으로 이동합니다.
3. 게시글 제목을 클릭하고 상세 페이지가 열리는지 확인합니다.
4. 게시판으로 돌아와 `글쓰기`를 누릅니다.
5. 제목과 내용을 입력하고 등록합니다.
6. 등록 후 상세 페이지로 이동하고, 게시판 목록에 글이 보이는지 확인합니다.

## API 연결
- `GET /api/posts/{postId}`
- `POST /api/boards/{boardId}/posts`
- 작성 요청 JSON: `title`, `content`, `categoryId` (카테고리는 선택 사항)

## 참고
- 백엔드 API를 변경하지 않습니다.
- 실제 브라우저/백엔드 실행 환경에서의 통합 테스트는 프로젝트 PC에서 적용한 뒤 확인해야 합니다.
