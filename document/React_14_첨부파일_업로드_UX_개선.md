# React 14차 — 첨부파일 업로드 UX 개선

## 목적
기존 첨부파일 업로드/다운로드/삭제 API는 그대로 유지하고, 업로드 전에 파일을 확인하고 선택 실수를 수정하기 쉽게 만든다.

## 변경 파일

- `front/src/components/AttachmentsSection.jsx` — 현재 첨부파일 컴포넌트를 아래 기능으로 갱신
- `front/attachment-upload-ux.css.txt` — 기존 `front/src/App.css` 맨 아래에 추가할 스타일

## 변경 사항

1. 파일 선택 버튼 외에 드래그 앤 드롭으로도 파일을 선택할 수 있다.
2. 파일당 10MB 초과, 빈 파일을 선택 단계에서 거부하고 이유를 보여 준다.
3. 동일 파일(이름·크기·수정 시각 기준)을 중복으로 선택하지 않는다.
4. 업로드 대기 파일을 목록으로 표시하고 파일명·크기·전체 용량을 보여 준다.
5. 개별 파일을 제거할 수 있다. 업로드 중에는 선택 목록 편집을 막는다.
6. 업로드가 일부 실패하면 성공한 파일은 대기 목록에서 제외하고 실패한 파일은 남겨 재시도할 수 있다.
7. 기존 다운로드, 삭제 확인, 기존 파일 목록과 API 경로는 유지한다.

## 수동 확인 시나리오

- 파일 선택 버튼으로 하나 또는 여러 파일 선택
- 파일을 드롭존으로 끌어 놓기
- 10MB를 초과하는 파일 또는 빈 파일 선택 시 경고 확인
- 동일한 파일을 다시 선택했을 때 중복 안내 확인
- 대기 목록의 일부 파일만 제거
- 성공한 파일이 서버 목록에 나타나는지 확인
- 일부 업로드가 실패하면 해당 파일이 대기 목록에 남아 재시도 가능한지 확인
- 다운로드 및 삭제 동작이 기존과 같이 작동하는지 확인

## 검증 범위와 주의점

JSX 문법 파싱과 CSS 중괄호 균형, ZIP 무결성을 확인한다. 실제 브라우저와 백엔드를 연결한 통합 테스트는 별도로 수행해야 한다. 중복 파일 판단은 브라우저 File 객체의 이름·크기·마지막 수정 시각을 기준으로 하므로, 서로 다른 원본 파일이 그 세 가지 값까지 같을 때는 중복으로 판단될 수 있다.
