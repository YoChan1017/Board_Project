# React 16차 — 통합 검색

## 목적

여러 게시판을 오가며 검색할 필요 없이, 한 화면에서 게시글 제목·내용 검색 결과를 확인할 수 있게 한다.

## 변경 파일

- `front/src/pages/GlobalSearchPage.jsx` (신규): 통합 검색 화면
- `front/src/App.jsx`: 보호된 `/search` 라우트 등록
- `front/src/components/AppLayout.jsx`: 로그인 메뉴에 `통합 검색` 링크 추가
- `front/src/App.css`: 스타일 추가

## 제공 기능

- 전체 게시판 또는 선택한 단일 게시판 범위 검색
- 검색어를 URL의 `q` 파라미터에 보관하여 검색 링크를 공유하거나 새로고침해도 검색어 복원
- 최신순, 조회수순, 좋아요순, 제목 가나다순 정렬
- 페이지당 10개·20개·50개 결과 표시 및 클라이언트 페이지 이동
- 일부 게시판 검색 실패를 안내하고 성공한 게시판 결과는 표시
- 백엔드가 게시판별 검색 API만 제공하므로, 각 게시판에서 최대 100개 결과를 읽는다. 특정 게시판의 검색 매칭 건수가 100개를 넘으면 안내 문구를 표시한다.
- 백엔드 API 및 데이터베이스 스키마 변경 없음

## 검증 범위

JSX 문법 파싱, CSS 중괄호 균형, ZIP 무결성 검사 대상으로 한다. 실제 브라우저와 백엔드 연결 테스트는 별도로 수행해야 한다.
