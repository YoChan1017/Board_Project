# React 15차 — 내 활동: 최근 본 게시글

## 목표
백엔드 API가 제공하지 않는 사용자별 전체 게시글/댓글 기록 조회 기능을 임의로 가정하지 않고, 기존 게시글 상세 조회 결과를 활용해 브라우저 로컬의 최근 방문 기록을 제공한다.

## 변경 파일
- `front/src/App.jsx`: 로그인 사용자용 보호 라우트 `/activity` 추가
- `front/src/components/AppLayout.jsx`: 인증 사용자 내비게이션에 `내 활동` 추가
- `front/src/pages/PostDetailPage.jsx`: 게시글 상세가 성공적으로 로드되면 계정별 방문 기록 저장
- `front/src/pages/MyActivityPage.jsx`: 최근 본 게시글 목록, 검색, 방문 게시판 요약, 개별/전체 삭제
- `front/src/utils/recentPostHistory.js`: localStorage 접근, 중복 제거, 최대 30개 유지, 계정별 키 분리
- `front/src/App.css`: 스타일 추가분.

## 데이터 및 제한
한 항목에 저장하는 정보는 게시글 ID, 제목, 작성자 닉네임, 게시판 ID, 카테고리명, 작성 시각, 마지막 방문 시각이다. 본문은 저장하지 않는다. 최근에 열어 본 게시글 30개까지만 유지한다.

기록은 `board_project_recent_posts_v1_<account>` 형식의 계정별 localStorage 키에 보관한다. 서버로 전송되거나 기기간 동기화되지 않는다. 지금 구현하는 기능은 `최근 본 게시글`이며, 작성한 게시글 전체 목록이나 작성 댓글 전체 목록과 같은 서버 측 활동 기록은 아니다. 이를 구현하려면 추후 백엔드에 사용자 ID 기반 조회 API를 추가해야 한다.

## 확인 시나리오
1. 로그인한 상태에서 게시글 상세 화면을 열고 `/activity`로 이동한다.
2. 기록이 가장 최근 방문순으로 나타나는지 확인한다.
3. 검색으로 제목/작성자/게시판 이름/카테고리를 찾는다.
4. 개별 기록 삭제 후 새로고침해도 제거된 상태인지 확인한다.
5. 전체 기록 삭제 후 빈 화면 안내가 나타나는지 확인한다.
6. 다른 계정으로 로그인했을 때 서로 다른 기록이 표시되는지 확인한다.

## 검증 범위
JSX 구문 파싱, CSS 중괄호 균형, ZIP 무결성 검사를 수행한다. 실제 백엔드 통합/브라우저 테스트는 적용 후 확인이 필요하다.
