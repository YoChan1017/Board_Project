# React 08 — 반응형 UI 및 상태 피드백 개선

## 목표

1. 작은 화면에서 관리자 메뉴가 포함된 헤더가 가로로 넘치지 않도록 접이식 내비게이션을 제공한다.
2. 로딩, 오류, 성공 알림, 빈 목록 상태의 표현을 기존 CSS 클래스 위에서 일관되게 정리한다.
3. 게시판 목록, 게시글 상세·작성, 관리자 게시판·게시글 관리, 댓글, 첨부파일 화면의 작은 화면 레이아웃을 보강한다.
4. `textarea`, `select`를 포함한 키보드 포커스 표시와 `prefers-reduced-motion` 환경을 지원한다.

## 작업 내용

- `front/src/components/AppLayout.jsx`: 접근성 속성을 갖춘 모바일 내비게이션 버튼과 접이식 메뉴 추가. 기존 링크 및 권한별 관리자 메뉴 유지.
- `front/ui-feedback-responsive.css.txt`: `front/src/App.css`에 추가할 CSS. 상태 표시 스타일, 모바일 헤더, 표 스크롤, 댓글/첨부파일/관리자 화면 미디어 쿼리를 포함.

## 구현 노트

- 모바일 메뉴는 760px 이하에서 활성화한다.
- 경로가 변경되거나 사용자가 메뉴 항목을 누르면 메뉴가 닫힌다.
- 오류·성공·로딩 요소는 새 상태 관리 로직을 추가하지 않고 기존 페이지의 클래스에 스타일을 적용한다.
- 게시판 표와 관리자 게시글 표는 작은 화면에서 열을 억지로 압축하지 않고 가로 스크롤을 허용한다.
- 서버 측 인가가 실제 권한 검사의 기준이며, 이 작업은 API나 권한 검사를 변경하지 않는다.

## 수동 확인 체크리스트

- [ ] 데스크톱에서 메뉴가 기존처럼 보인다.
- [ ] 모바일 메뉴 열기/닫기 버튼이 동작하고 `aria-expanded`가 정확하다.
- [ ] 브라우저 뒤로 가기 등 경로 변경 뒤 메뉴가 닫힌다.
- [ ] 일반 사용자 계정에는 관리자 전용 메뉴가 보이지 않는다.
- [ ] 320px, 375px, 768px, 1280px 화면 폭에서 레이아웃을 확인한다.
- [ ] 긴 제목, 댓글, 파일명이 카드 너비를 밀어내지 않는다.
- [ ] 오류·로딩·성공·빈 상태가 구분되어 표시된다.
- [ ] 키보드 Tab 이동 시 포커스 표시가 보인다.
