# React 12차 — 게시판 정렬·페이지 크기와 작성 폼 개선

## 목표

현재 백엔드 게시글 조회 API를 유지하면서 목록 탐색 옵션을 추가하고, 작성/수정 폼에서 긴 본문을 확인하기 쉽게 만든다.

## 변경 파일

- `front/src/pages/BoardsPage.jsx`
- `front/src/pages/PostCreatePage.jsx`
- `front/src/pages/PostEditPage.jsx`
- `front/src/components/PostContentField.jsx` (신규)
- `front/board-and-form-usability.css.txt` (기존 `front/src/App.css` 끝에 추가)

## 기능 설명

### 게시판 목록

- 페이지당 게시글 개수를 10/20/50개 중 선택할 수 있다. 선택을 변경하면 첫 페이지부터 다시 요청한다.
- 현재 조회된 페이지 안에서 제목 가나다순, 조회수순, 좋아요순으로 정렬할 수 있다.
- 최신순은 API가 반환하는 최신 작성순을 그대로 사용한다.
- 정렬은 서버 전체 결과가 아니라 현재 페이지 데이터에만 적용된다는 점을 화면에 표시했다. 백엔드 API의 정렬 계약을 바꾸지 않는다.
- 검색어, 페이지 크기, 게시판 선택이 변경될 때 목록 페이지를 0으로 초기화한다.

### 게시글 작성·수정

- 제목 200자 카운터에 접근성 설명을 연결했다.
- 새 공통 컴포넌트 `PostContentField`에서 본문 글자 수를 실시간으로 표시한다.
- `미리보기 보기` 버튼으로 줄바꿈을 보존한 평문 미리보기를 열고 닫을 수 있다.
- 입력을 수정하면 이전 제출 오류 안내를 지운다.
- 제출 중에는 입력 컨트롤을 비활성화해 요청 중 내용이 달라지는 상황을 막는다.

## API/DB 변경

없음. 기존 `GET /api/boards/{boardId}/posts?page=&size=&keyword=`와 기존 게시글 작성·수정 API를 사용한다.

## 검증 범위

JSX 문법 파싱, CSS 중괄호 균형, ZIP 무결성 확인 대상으로 삼는다. 백엔드와 연결된 브라우저 통합 검증은 별도 수행해야 한다.
