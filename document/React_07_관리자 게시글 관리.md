# 프론트엔드 7차 작업: 관리자 게시글 관리

## 제공 기능
- 관리자 메뉴에서 `/admin/posts` 진입
- 게시판 선택 후 게시글 목록 조회
- 제목/본문 키워드 검색 및 서버 페이지네이션
- 게시글 상세 페이지로 이동
- 게시글 삭제(확인 창 포함) 후 목록 새로고침
- 요청 실패 및 성공 메시지 표시

## API 매핑
- `GET /api/boards`
- `GET /api/boards/{boardId}/posts?page={page}&size=10&keyword={keyword}`
- `DELETE /api/posts/{postId}`
- `GET /api/posts/{postId}` (상세 확인 화면)

## 설계상 한계
현재 백엔드에는 모든 게시판의 게시글을 한 번에 조회하는 관리자 전용 API가 없습니다. 따라서 관리자 화면도 한 번에 하나의 게시판을 선택하며, 해당 게시판 내에서만 검색/페이지네이션합니다. 삭제는 기존 백엔드의 소프트 삭제 API를 사용합니다. 프론트엔드의 `AdminRoute`는 사용성 계층이며 최종 권한 검사는 서버에서 수행됩니다.

## 확인 항목
- [ ] 관리자 메뉴에 `글 관리`가 표시된다.
- [ ] `/admin/posts`에서 일반 사용자 접근이 제한된다.
- [ ] 게시판 선택에 따라 게시글 목록이 변경된다.
- [ ] 제목/본문 키워드 검색과 이전/다음 페이지가 동작한다.
- [ ] 상세 링크는 해당 게시글 상세 페이지를 연다.
- [ ] 삭제 확인 후 게시글이 목록에서 사라진다.
- [ ] 서버 삭제 거부/권한 오류가 발생하면 메시지가 표시된다.
