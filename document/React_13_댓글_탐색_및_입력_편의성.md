# React 13차 — 댓글 탐색 및 입력 편의성

## 목적

기존 댓글/대댓글 API를 유지하면서 긴 댓글 목록을 탐색하기 쉽게 만들고, 댓글 작성·수정 작업의 입력 흐름을 보완합니다.

## 변경 파일

- `front/src/components/CommentsSection.jsx` — 댓글 영역 교체
- `front/comment-thread-ux.css.txt` — `front/src/App.css` 맨 아래에 추가할 스타일

## 기능

1. **댓글 스레드 페이지 이동**: 최상위 댓글을 기준으로 페이지당 8개 스레드를 보여줍니다. 대댓글과 후속 답글은 부모 댓글과 함께 표시되어 페이지 경계에서 분리되지 않습니다.
2. **댓글 검색**: 작성자 닉네임 또는 댓글 내용으로 검색합니다. 일치하는 대댓글이 있는 경우 그 대댓글이 속한 스레드 전체를 표시합니다.
3. **빠른 제출**: 댓글·답글 입력창에서 Ctrl+Enter 또는 macOS의 Command+Enter로 폼을 제출할 수 있습니다. 댓글 수정창에서도 같은 키 조합으로 저장합니다.
4. **작업 안내**: 등록, 수정, 삭제 성공 알림과 검색 결과/스레드 범위를 화면에 표시합니다.
5. **상태 처리**: 로딩·오류·빈 결과를 공통 피드백 컴포넌트로 표시합니다.

## 정렬 및 페이지 처리 범위

현재 백엔드 `GET /api/posts/{postId}/comments`는 댓글 전체 목록을 반환하고 페이지 파라미터를 제공하지 않습니다. 따라서 댓글 검색과 페이지 이동은 **브라우저에서 이미 받은 댓글 목록에 대해 처리**합니다. 이 단계에서는 백엔드 API를 변경하지 않았습니다. 댓글 수가 매우 큰 게시글에 서버 측 페이징을 적용하려면 이후 API 변경이 필요합니다.

## 검증 범위

JSX 파서 구문 검사, CSS 중괄호 균형 검사, ZIP 파일 무결성 검사를 수행합니다. 실제 브라우저와 백엔드를 연결한 통합 테스트는 별도로 수행해야 합니다.
