# React 11차 — 게시판 및 게시글 상세 화면 사용성 개선

## 작업 목적

게시판 목록에서 검색과 재시도 동작을 더 명확하게 분리하고, 게시글 상세 링크를 손쉽게 공유할 수 있도록 합니다. 기존 API 계약과 권한 정책은 변경하지 않습니다.

## 변경 사항

### 1. 게시판 목록 (`BoardsPage.jsx`)

- 게시판 목록 조회 오류와 게시글/카테고리 조회 오류를 별도로 관리합니다.
- 게시판 오류는 게시판 목록 재조회로, 게시글 오류는 현재 게시판 콘텐츠 재조회로 다시 시도합니다.
- 입력 중인 검색어만 있을 때도 초기화 버튼이 보여 검색 입력값을 즉시 지울 수 있습니다.
- 검색 초기화 시 입력값, 적용 검색어, 페이지, 관련 오류 상태를 함께 초기화합니다.
- 검색 결과의 검색어와 결과 개수를 표시하고 로딩 중 검색/페이지 이동을 제한합니다.
- 조회수 및 좋아요 수를 한국어 숫자 형식으로 표시합니다.
- `aria-busy`, 검색 폼의 `role="search"`, 상태 영역을 적용해 보조기기 피드백을 개선합니다.

### 2. 게시글 상세 (`PostDetailPage.jsx`)

- 상세 상단에 `링크 복사` 버튼을 추가했습니다.
- 브라우저 Clipboard API가 지원되고 권한이 허용되면 현재 게시글 URL을 복사합니다.
- 성공 또는 권한/지원 문제를 `role="status"` 영역에서 사용자에게 알립니다.
- 상단 경로 탐색과 공유 버튼을 모바일에서 세로로 배치하도록 보완했습니다.
- 게시글을 새로 전환할 때 기존 게시글 데이터가 남아 있는 상태를 피하도록 로딩 시작 시 상세 데이터를 초기화합니다.
- 기존 댓글, 첨부파일, 좋아요, 작성자/관리자 편집·삭제 기능은 유지합니다.
